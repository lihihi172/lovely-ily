# Yêu website — Lưu Ly ❤️ Hồng Phúc

## Cấu trúc
- `index.html` — toàn bộ HTML + CSS + JavaScript
- `music.mp3` — nhạc nền, phát loop
- `images/anh1.jpg` đến `anh4.jpg` — 4 ảnh kỷ niệm

## GitHub Pages
Upload toàn bộ nội dung thư mục này vào repository, sau đó bật GitHub Pages với:
- Branch: `main`
- Folder: `/ (root)`
